FAQ

Questions? Answered.

Everything you need to know about Aryo Video Player.

Is Aryo Video Player really free? +

Yes — 100% free, no hidden costs, no premium tier, no ads, no telemetry. Built as a passion project by a single developer.

What video formats are supported? +

All major formats including MP4, AVI, MKV, MOV, WMV, FLV, WebM. Because Aryo uses LibVLC under the hood, it can play virtually anything VLC can play — including 4K HDR content.

Does it support subtitles? +

Yes! Aryo supports SRT, ASS and SUB subtitle files. It also features live translation to 100+ languages, dual subtitles (original + translation), and an offline audio-to-text engine powered by Vosk.

What are the system requirements? +

Windows 10 or 11 (64-bit), .NET 9 Desktop Runtime (auto-installed), and about 120 MB of disk space. Works on any modern PC.

Is the source code available? +

The binary is free to download. The full source code repository will be available on GitHub soon. Star the repo to be notified.

Why is it called "Aryo"? +

Aryo is named after Ariobarzanes (آریو برزن) — a legendary Persian commander who, with only 2,500 soldiers, held the Persian Gate against Alexander the Great's 40,000-strong army. The player is a tribute to that spirit of courage and craft.

How do I report a bug or request a feature? +

Reach out via Telegram at @Thesurenax or open an issue on the GitHub repository. We read everything.
